R11 세그멘테이션 CPU 폴백 3자 A/B — 같은 프레임, 세 런타임

한 카메라 프레임을 288×160으로 줄여 세 런타임에 동일한 float 배열로 먹인다. 출력(2채널 로짓)을 각자 softmax해 사람 확률 마스크를 그레이스케일로 보여준다. 모델: ai-cpu·ORT는 같은 onnx 계보의 fp32, tflite는 v-ai 프로덕션과 동일한 float16 가중치 export — tflite 마스크의 미세한 차이는 가중치 정밀도 차이다.

스레드: 이 페이지는 COOP/COEP 헤더 없이 서빙되므로 crossOriginIsolated=false — 세 런타임 모두 1스레드다 (v-ai 배포 기본 조건과 동일). ms = 추론 호출을 감싼 벽시계. ai-cpu는 wasm 내부에서 잰 순추론 p50/p90도 따로 보여준다.
